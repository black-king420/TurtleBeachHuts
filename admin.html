Connection

This dashboard reads and writes the same data as the public site: Firestore collections bookings, messages, newsletter and catalog when Firebase is configured, or localStorage on this device otherwise.

Admin access

Add or remove the emails allowed into this dashboard in ADMIN_EMAILS inside js/firebase-config.js, then mirror the same list in your Firestore security rules.

Exports

“Export” on Bookings and Messages creates a real .xlsx file in your browser from exactly what's on screen, including any active search or filter. “Export all” bundles both into one workbook.
