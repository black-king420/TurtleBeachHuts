Connection

This dashboard reads and writes the same data source as the public site: Firestore collections bookings, messages and newsletter when Firebase is configured, or localStorage on this device otherwise.

Admin access

Add or remove the email addresses allowed into this dashboard in ADMIN_EMAILS inside js/firebase-config.js, then mirror the same list into your Firestore security rules (see the comment block at the bottom of that file).

Exports

"Export to Excel" on the Bookings and Messages tabs generates a real .xlsx file client-side (via SheetJS) from exactly what's on screen, including any active search/filter. "Export all to Excel" bundles both tables into one workbook with two sheets.
